# docs/datos

Diccionarios de datos y documentación de los datasets. Acá quedan escritas las decisiones sobre los datos (target, features, formato, protocolo de validación).

| Archivo | Origen | Contenido |
|---|---|---|
| `fraud_dataset_documentation.pdf` | Cátedra | Documentación oficial de las columnas de `fraud_dataset.csv` |
| `fraud_dataset.md` | Se genera en F09 | Columnas, significado, rangos, target, features finales, limpieza |
| `digits.md` | Se genera en F12 (+ F13) | Formato de imagen, protocolo de validación, balance, duplicados, comparación digits / more_digits / digits_test |

Los CSV no se versionan: cada integrante los copia a `datasets/` (ver `.gitignore`).
